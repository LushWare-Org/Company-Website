# projects

LushWare's Service Specializations & Packages web app, built with React + Vite.

## Getting started

```bash
npm install
npm run dev
```

Then open the printed local URL in your browser.

## Build for production

```bash
npm run build
npm run preview
```

## Structure

- `src/pages/Home.jsx` — the five service-specialization domains, each with a build blueprint and industry applications.
- `src/pages/Packages.jsx` — engagement packages for Founders, Business, and Partners.
- `src/data/` — all copy and structured content, kept separate from presentation.
- `src/components/` — reusable UI building blocks (tabs, stepper, industry grid, pricing cards, icons).
